# 拼图装置视觉程序（RDK X5）

本目录只实现视觉运算，不包含电机、机械臂或电磁铁控制。程序从一张俯拍图像中完成：

1. 自动检测 A4 纸四角并校正透视；
2. 以 A4 实际尺寸 `210 mm × 297 mm` 自动建立毫米坐标系；
3. 分割上半区的 1～4 块碎片并拟合 3～5 边多边形；
4. 输出每块碎片的安全吸取点、目标放置点和旋转角；
5. 固定题使用预设模板匹配，未知题枚举边连接并寻找矩形；
6. 扑克牌模式在几何候选之间比较接缝纹理连续性。

摄像头高度不是配置项。只要画面能完整看到 A4 纸，比例就由 A4 四角和已知尺寸自动计算。摄像头虽默认垂直安装，程序仍会用单应变换补偿小角度倾斜。

## 无上位机独立运行

网页上位机不是视觉计算的必要条件。RDK X5 可以在不连接 Windows 电脑、浏览器或显示器时，让 `vision_server.py` 作为开机服务持续识别，并由板内机械臂进程通过 `http://127.0.0.1:8000/api/status` 和 `/api/export-motion.json` 取得动作。

完整的 systemd 开机自启配置、机械臂安全读取规则、旧方案防重放、实体按键/GPIO 触发流程及故障恢复，请阅读交付包中的：

```text

```

## 板端运行

```bash
cd /home/sunrise/puzzle_vision

# 无摄像头时先运行合成画面自测
python3 main.py self-test --output-dir self_test_output

# 摄像头接好后抓一张原始画面
python3 main.py capture --source auto --output capture.jpg

# 推荐先拍一张没有碎片、只有 A4 和分界线的背景
python3 main.py background --source auto \
  --output background_rectified.png \
  --debug background_camera.jpg

# 固定四片题
python3 main.py analyze --source auto --mode fixed \
  --background background_rectified.png \
  --result result.json --debug debug.jpg

# 现场全白未知碎片
python3 main.py analyze --source auto --mode unknown-white \
  --background background_rectified.png \
  --result result.json --debug debug.jpg

# 扑克牌图案碎片
python3 main.py analyze --source auto --mode unknown-pattern \
  --background background_rectified.png \
  --result result.json --debug debug.jpg
```

`--source` 可取：

- `auto`：先找 USB 摄像头，再尝试 RDK MIPI；
- `mipi`：RDK X5 MIPI 摄像头；
- `usb:/dev/video0`：指定 Linux USB 摄像头；
- 一个 JPG/PNG 文件路径：离线调试。

## 输出接口

`result.json` 坐标定义：

- 原点：A4 左上角；
- 单位：毫米；
- X 正方向：向右；
- Y 正方向：向下；
- 旋转正方向：顺时针。

每项动作包含：

```json
{
  "piece_id": "piece_1",
  "pick_mm": [52.1, 43.8],
  "place_mm": [82.4, 216.7],
  "rotate_deg": -31.5,
  "target_polygon_mm": [[...], [...]]
}
```

机械控制部分以后只需读取 `pick_mm`、`place_mm` 和 `rotate_deg`。视觉坐标到机械坐标的刚体标定不属于当前程序范围。

## 实时上位机

### 地瓜派版

Windows 电脑连接到与地瓜派相同的网络后，在本目录运行：

```powershell
python .\upper_computer.py
```

脚本会通过 SSH 启动地瓜派上的视觉服务，并打开
`http://192.168.1.9:8000/`。界面默认使用固定四片模式，可以设置 A4
纸颜色和碎片颜色。“基础识别”严格按题目图 2 的固定四片模板匹配；
“提高识别”才根据现场 2～4 片的边长、角点和接缝自主搜索矩形，并可进一步
选择纯色或花纹接缝。实时图像会同时标出 A4 边框、分界线、四块原始碎片
及重心；下半区的目标矩形内会显示四块碎片的目标轮廓、内部拼缝、目标
重心和旋转角。基础模式要求题图规定的 4 片；提高模式支持 2～4 片。
只有拼接填充度、几何误差、无重叠和轮廓完整度均通过时，界面才显示
`MOTION READY`。

实时模式只锁定下半区的拼接方式：源碎片未移动时，多个等价解不会导致
目标块位、放置点或旋转角跳变；A4、分界线、源碎片边框、重心和吸取点
仍持续更新。若新方案质量明显更高则允许替换旧方案，任一碎片移动后也会
立即重新选择。界面上的“重新选择下方拼法”按钮可手动丢弃当前拼法。
识别不完整或碎片重叠时不会锁定，但仍显示当帧能够识别的视觉信息。

所有求解变换均限制为平移和二维旋转，旋转矩阵行列式必须为 `+1`；
禁止镜像、翻面或带缩放的变换。结果中同时输出 `"mirrored": false`。

颜色提示默认开启。现场换色时先在上位机设置 A4 底纸和碎片颜色；如果
颜色选择不方便或自动分割效果更好，也可以取消“优先按指定颜色寻找”。

黑色或深灰色 A4 会额外启用亮度轮廓候选，以减小暗部渐变和反光造成的
断边。黑纸上的银色/白色分界线按亮线检测，普通彩纸上的黑色分界线仍按
暗线检测。环境中若还有其他大块深色物体，建议把“A4 底纸颜色”设为
黑色并勾选“优先按指定颜色寻找”。上传照片会强制重新定位 A4，不会
复用实时摄像头的旧纸张坐标。

地瓜派版和电脑版网页都支持图片识别：选择 JPG、PNG 或 BMP 后点击
“识别选中图片”，图片会使用当前识别方式、颜色和碎片区域设置进行计算，
并保持显示识别结果；点击“恢复实时摄像头”即可切回实时画面。地瓜派版
的上传图片由地瓜派完成运算，浏览器只负责选择文件和显示结果。

切换到“提高识别｜自主拼接（花纹）”后，上位机显示独立的扑克牌参数
面板，可调整整牌长短边范围、比例、圆角、花纹/反光阈值、同形碎片消歧
权重和搜索时间。数值不会边输入边触发耗时解算；点击“应用并保存”后才
校验、生效并写入 `config.json`。扑克牌权重与纯色算法隔离，不会拖慢
基础模式或白片模式。详细调节方法见
[`扑克牌识别与上位机参数说明.md`](./扑克牌识别与上位机参数说明.md)。

切换到“提高识别｜自主拼接（纯色）”后，上位机显示普通白片参数面板，
可调整目标矩形尺寸、单片面积、直边拟合、形态学去噪、环境光下的
Lab 明暗/色度/背景差阈值、颜色提示容差，以及白片求解的接缝容差和时间。
这些值单独保存在 `config.json` 的 `white_tuning` 中，仅对白片模式叠加，
不会改变基础题模板或扑克牌流水线。详细说明见
[`普通白片识别与上位机参数说明.md`](./普通白片识别与上位机参数说明.md)。

每次得到 `MOTION READY` 结果后，上位机会自动生成：

- `exports/latest_motion_plan.json`
- `exports/latest_motion_plan.csv`

网页中的“下载机械臂 JSON/CSV”可直接取得同一份动作方案。每块碎片均
输出执行顺序、A4 毫米坐标下的安全吸取点和放置点、相机像素坐标、顺时针
旋转角以及 `mirrored=false`。机械臂控制程序优先读取 A4 毫米坐标，再通过
现场手眼标定转换为机械臂坐标；相机像素坐标主要用于调试核对。

需要停止板端视觉服务时运行：

```powershell
python .\upper_computer.py --stop
```

### 电脑版

电脑本地直接完成摄像头读取、视觉计算和网页显示，不需要连接地瓜派：

```powershell
python -m pip install -r .\requirements_pc.txt
python .\upper_computer_pc.py
```

也可以双击 `启动电脑版上位机.bat`。默认使用电脑的第 0 个 USB 摄像头；
指定其他摄像头或离线图片：

```powershell
python .\upper_computer_pc.py --source usb:1
python .\upper_computer_pc.py --source .\test.jpg
```

电脑版启动后访问 `http://127.0.0.1:8000/`，界面和算法与地瓜派版一致。
保持启动命令窗口开启，按 `Ctrl+C` 可停止服务。

## 固定四片模板

`config.json` 中的固定模板按图 2 建立：

- 外矩形为 `100 mm × 60 mm`；
- 上边分段为 `20 mm + 80 mm`；
- 左边分段为 `20 mm + 10 mm + 30 mm`；
- 图中两条标注内边分别为 `20 mm` 和 `30 mm`。

图 2 没有给出第一个内部点的唯一坐标，因此默认令 20 mm 内边与水平方向成 45°。实际加工的碎片如果采用其他角度，只需修改 `fixed.pieces[*].vertices_mm`，视觉主程序不需要改动。

## 现场注意

- A4 与桌面需要有明显边界，碎片与 A4 底色需要有明显色差；
- 上位机可以指定 A4 和碎片颜色，程序按 Lab 色度自适应曝光变化；
- 摄像头必须看到整张 A4，纸边不能被机构遮挡；
- 固定曝光和白平衡能提高背景差分稳定性；
- 调试图中，上半区多边形是识别结果，下半区多边形是计算出的目标位置。
## 2026-07-29 最新优化

- A4 检测优先利用“底纸与周围桌面有明显色差”以及题目规定的中部分界线，同时用 A4 的 210×297 mm 比例约束透视四角。
- 分界线只用于获得可靠的 A4 粗框；程序随后回到相机原始分辨率，沿四条外边搜索连续 Lab 颜色跃迁、重新拟合直线并求交点。该精修会修正分界线没有画到纸边造成的缺框/多框，并在校验失败时安全回退。
- 颜色选择器使用相对 Lab 色差，不要求摄像头拍到的 RGB 与网页色块完全一致；设置修改后会立即触发重新识别，不再被状态轮询覆盖。
- 提高模式支持 2～4 块碎片。正式题目的 3～5 边规则不变；为了兼容手工切割、褶皱和边缘阴影，视觉轮廓允许一次 6 顶点容错。
- 若颜色提示把 A4 外侧亮条与碎片粘连，程序会检查二值轮廓是否接触 A4 有效区边界，并自动改用亮度/综合色差分割。
- 与识别区边界长距离连通的候选不会被一律删除：程序还会和内部碎片比较 Lab 颜色。同色的边缘碎片保留，颜色更像桌面、阴影或透视残边的分量才删除，因此兼顾防误识别和防漏识别。
- 未知拼图采用精确边、T 形部分边、多锚点和矩形全局填充评分。展示拼法只作为邻接与朝向提示，最终方案仍须通过无镜像、无重叠和矩形填充检查。
- 当全部碎片相对展示时整套翻面，程序会选择“展示布局的全局镜像版本”；每一块碎片的机械动作仍然只有旋转和平移，绝不对单块执行镜像。
- OpenCV 使用多 CPU 线程；同一场景解算成功并锁定后，重复帧使用轻量变化检测，实测缓存帧约 20 ms，不会让下方拼法来回跳变。
- 当前地瓜派 USB 实测：4 块识别、目标矩形约 99.4×71.1 mm、填充率约 99.8%，`MOTION READY` 和机械臂 JSON/CSV 导出均已通过。
