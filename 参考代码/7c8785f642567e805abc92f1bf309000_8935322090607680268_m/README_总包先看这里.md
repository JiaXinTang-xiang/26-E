# A4 拼图视觉全版本总包

版本日期：2026-07-31

本文件夹把以下三个可运行版本放在一起：

1. RDK X5 有上位机版；
2. RDK X5 无上位机独立运行版；
3. Windows PC 本机版。

三个版本使用同一代视觉算法。RDK 两版的识别、拼图、禁止镜像、机械臂坐标输出完全相同，区别仅在启动方式和服务监听地址。

## 目录结构

```text
01_RDK_X5_有上位机版/

  启动有上位机模式.sh

  启动电脑版上位机.bat
  安装依赖_首次运行.bat

04_RDK_X5部署工具/
  一键部署RDK_X5_有上位机版.bat
  一键部署RDK_X5_无上位机版.bat
```

## 应该选择哪个版本

| 使用场景 | 选择 |
|---|---|
| 比赛调试，需要实时看边框、阈值和拼图 | `01_RDK_X5_有上位机版` |
| 比赛正式运行，不接电脑和显示器 | `02_RDK_X5_无上位机版` |
| 不使用 RDK，摄像头直接接 Windows 电脑 | `03_Windows_PC版` |

## RDK X5 有上位机版

Windows 电脑进入 `04_RDK_X5部署工具`，双击：

```text
一键部署RDK_X5_有上位机版.bat
```

部署后浏览器访问：

```text
http://RDK_IP:8000/
```

手动在板端启动：

```bash
cd /home/sunrise/puzzle_vision
chmod +x *.sh
START_MODE=fixed ./启动有上位机模式.sh
```

## RDK X5 无上位机版

Windows 电脑进入 `04_RDK_X5部署工具`，双击：

```text
一键部署RDK_X5_无上位机版.bat
```

部署脚本会把服务限制为板内访问，不需要浏览器：

```text
状态：http://127.0.0.1:8000/api/status
动作：http://127.0.0.1:8000/api/export-motion.json
```

需要开机自动运行时，在板端执行：

```bash
cd /home/sunrise/puzzle_vision
chmod +x *.sh
START_MODE=fixed ./安装无上位机开机自启.sh
```

普通白片把模式改为 `unknown-white`，扑克牌或花纹碎片改为 `unknown-pattern`。

**机械臂不能只因为磁盘上存在 JSON 就执行。** 必须实时确认 `motion_ready=true`，连续稳定后锁定本轮方案，机械臂进入画面后不再重新读取。

## Windows PC 版

进入 `03_Windows_PC版`：

1. 首次双击 `安装依赖_首次运行.bat`；
2. 双击 `启动电脑版上位机.bat`；
3. 浏览器自动打开 `http://127.0.0.1:8000/`。

默认相机不是目标相机时：

```bat
启动电脑版上位机.bat usb:1 fixed
```

依次尝试 `usb:0`、`usb:1`、`usb:2`。

## 三种识别模式

| 模式 | 用途 |
|---|---|
| `fixed` | 题图规定基础碎片，速度最快 |
| `unknown-white` | 2～4 块普通白片或纯色片 |
| `unknown-pattern` | 扑克牌、印刷花纹和反光碎片 |

扑克牌算法只在 `unknown-pattern` 运行，不会拖慢基础模式和普通白片模式。

## 共同安全要求

- 摄像头必须完整看见 A4 四边；
- 分界线贯穿 A4，碎片全部位于指定源区域；
- 碎片互不重叠；
- 本题只允许旋转和平移，所有 `mirrored` 必须为 `false`；
- 只有 `MOTION READY` 才允许机械臂抓取；
- A4 毫米坐标转换到机械臂坐标前必须完成现场标定；
- 相机断开、识别失败、坐标越界或动作数量异常时必须停止。
