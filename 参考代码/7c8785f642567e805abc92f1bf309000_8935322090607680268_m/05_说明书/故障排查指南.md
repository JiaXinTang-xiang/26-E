# 故障排查指南

按“网络/服务 → 摄像头 → A4 → 分界线 → 碎片 → 拼图”的顺序排查。

## 1. 网页显示断线

Windows 本机：

```bat
curl http://127.0.0.1:8000/api/status
netstat -ano | findstr :8000
```

RDK X5：

```bash
ping RDK_IP
curl http://RDK_IP:8000/api/status
ssh sunrise@RDK_IP
pgrep -af 'python3 vision_server.py'
tail -n 100 /home/sunrise/puzzle_vision/vision_server.log
```

常见原因：

- IP 改变；
- 8000 端口被旧进程占用；
- Python 依赖缺失；
- 摄像头启动阻塞；
- 浏览器仍缓存旧地址。

## 2. 摄像头打不开

Windows：

- 关闭相机、微信、OBS 等占用程序；
- 尝试 `usb:1`、`usb:2`；
- 在“设置 → 隐私 → 相机”允许桌面程序访问；
- 拔插 USB，避免无供电扩展坞。

RDK：

```bash
v4l2-ctl --list-devices
fuser -v /dev/video0
v4l2-ctl -d /dev/video0 --list-formats-ext
```

选择真正提供视频格式的节点。

## 3. A4 没有框出

先确认：

- 四边完整进入画面；
- A4 没有被手、机械臂、胶带遮挡；
- A4 与桌面颜色有明显区别；
- 纸张面积不是过小或几乎占满画面。

再操作：

1. 网页设置正确 A4 颜色并勾选颜色优先；
2. 清空旧图片，恢复实时摄像头；
3. 固定曝光和白平衡；
4. 检查 `minimum_image_area_ratio`；
5. 最后才调整 `edge_refine_search_ratio`。

## 4. A4 框少一点或多一点

当前程序会先粗定位，再在原图上逐边精修。若仍有偏差：

- 减少纸边阴影；
- 避免透明胶带跨越边缘；
- 保留纸外至少 2～3 cm 桌面；
- 相机尽量垂直；
- 将 `edge_refine_search_ratio` 每次改 0.005；
- 不要直接使用 `corner_override_px` 作为长期方案。

## 5. 分界线找不到

- 线必须横贯大部分纸宽；
- 黑纸使用白色/银色线，浅色纸使用黑线；
- 避免碎片压住分界线；
- 检查检测位置是否在 A4 中部；
- 不要把地砖缝或桌面拼缝当作分界线。

错误中会显示支持对比度。对比很高但仍失败，通常是线不连续；对比很低则是光线或颜色问题。

## 6. 两块却识别成四块

先看二值掩膜：

- A4 外侧亮条进入透视图：检查 A4 绿框；
- 纸边残条：保持 `reject_roi_border_components=true`；
- 花纹被拆成碎片：扑克牌使用 `unknown-pattern`；
- 污点达到最小面积：提高 `min_area_mm2`。

边缘过滤会比较候选与内部真碎片的 Lab 颜色，真实同色贴边片不会被简单删除。

## 7. 少识别一块

- 碎片与 A4 对比太小；
- 两块接触或阴影连在一起；
- 小片面积低于 `min_area_mm2`；
- 小边低于 `minimum_detected_edge_mm`；
- 碎片压到被忽略的外边或分界线区域。

优先分开碎片、改善光线，再小幅降低面积/边长门限。不要一次放宽所有阈值。

## 8. 能识别碎片但不能拼矩形

检查顺序：

1. 碎片数量是否正确；
2. 每块结构顶点是否为 3～5；
3. 轮廓是否因为阴影多出缺口；
4. 总面积是否接近目标矩形；
5. 目标尺寸范围是否符合实际；
6. 是否错误选择基础模式；
7. 扑克牌是否选择花纹模式。

若输入轮廓正确，再调整 `edge_length_tolerance_mm`、搜索时间和尺寸范围。最终禁止镜像和无重叠检查不应关闭。

## 9. 拼接结果时有时无或来回变化

- 固定摄像头、曝光和灯光；
- 确认纸张与碎片没有移动；
- 等待一次高质量 `MOTION READY`；
- 不要持续拖动网页阈值；
- 检查 CPU 是否降频；
- 关闭其他占用摄像头或大量 CPU 的程序。

程序只锁定拼接方案，不冻结 A4、分界线和碎片检测；场景真正变化后会重新求解。

## 10. 识别速度慢

- 普通片不要使用 `unknown-pattern`；
- 基础题优先 `fixed`；
- 保持 A4 和摄像头稳定以命中缓存；
- RDK 检查散热；
- 降低输入分辨率前先确认小碎片仍有足够像素；
- 不要无限增加搜索秒数和候选数。

## 11. 机械臂执行前检查

必须同时满足：

- `motion_ready=true`；
- `mirrored=false`；
- `target_non_overlapping=true`；
- 计划数量等于碎片数量；
- 吸取点位于碎片内部；
- 放置点位于 A4 下半区；
- 角度方向与机械臂定义一致，程序输出为顺时针正方向。

现场先空载或低速走一遍，再打开吸盘。
