# 配置参数详细指南

配置文件：`config.json`。RDK X5 和 Windows PC 使用相同格式。

修改前先复制一份备份。JSON 不允许注释、末尾多余逗号或中文引号。网页颜色控件会覆盖本次运行中的颜色提示，但不会擅自改变物理尺寸。

## 1. 不应随意修改的物理基准

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `paper.width_mm` | 210 | A4 短边 |
| `paper.height_mm` | 297 | A4 长边 |
| `paper.divider_y_mm` | 148.5 | 理论中线位置 |
| `paper.pixels_per_mm` | 4 | 透视展开分辨率 |

摄像头高度不是参数。程序根据 A4 已知尺寸自动得到毫米比例。

## 2. A4 检测参数

| 参数 | 默认值 | 增大后的影响 |
|---|---:|---|
| `detection_max_dimension` | 960 | 粗定位更精细但更慢 |
| `fallback_detection_max_dimension` | 1600 | 困难场景回退更精细、更慢 |
| `minimum_image_area_ratio` | 0.045 | 排除太小候选，远距离 A4 可能漏检 |
| `maximum_image_area_ratio` | 0.78 | 排除几乎占满画面的错误区域 |
| `maximum_colour_aspect_error_ratio` | 0.14 | 接受更大透视/裁切误差，也更易误框 |
| `dark_paper_lightness_threshold_lab` | 92 | 更多深灰纸进入黑纸检测分支 |
| `color_hint_weight` | 0.8 | 更信任网页指定的 A4 颜色 |

建议 A4 在画面中占 20%～70%，四边与桌面保持可见间隔。

### 四边精修

| 参数 | 默认值 | 用途 |
|---|---:|---|
| `edge_refine_enabled` | true | 开启原图四边精修 |
| `edge_refine_search_ratio` | 0.055 | 在粗边两侧搜索范围占短边比例 |
| `edge_refine_max_search_px` | 72 | 最大搜索像素 |
| `edge_refine_probe_ratio` | 0.0045 | 比较纸内外颜色的采样距离 |
| `edge_refine_min_lab_step` | 5 | 接受外边的最小连续色差 |
| `edge_refine_groups` | 9 | 每条边分段拟合数量 |
| `edge_refine_max_angle_deg` | 4.5 | 相对粗边允许修正的最大角度 |
| `edge_refine_max_aspect_error_ratio` | 0.20 | 精修后 A4 比例安全校验 |

框少一点或多一点时，先改善纸边照明；再将 `edge_refine_search_ratio` 在 `0.04～0.075` 内小幅调整。不要直接把角度和比例容差放得很大。

## 3. 分界线参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `divider_search_half_range_mm` | 12 | 正常中线搜索半范围 |
| `divider_broad_search_half_range_mm` | 38 | 困难场景中央回退范围 |
| `divider_min_contrast_lab` | 12 | 正常最小 Lab 对比 |
| `divider_broad_min_contrast_lab` | 16.2 | 宽范围回退需要更强证据 |
| `divider_min_continuous_width_ratio` | 0.55 | 至少覆盖纸宽的比例 |
| `divider_horizontal_support_quantile` | 0.34 | 抑制局部碎片/反光 |
| `divider_max_horizontal_gap_ratio` | 0.035 | 允许线条中的小断点 |
| `divider_max_width_mm` | 5 | 题目规定值，当前仅作诊断 |

黑纸上的银色或白色线与彩纸上的黑线都会自动检测。不要为了识别地砖缝而降低连续宽度比例。

## 4. 碎片分割参数

| 参数 | 默认值 | 增大后的影响 |
|---|---:|---|
| `lab_distance_threshold` | 24 | 要求更大综合色差，误识别减少、浅色片可能漏检 |
| `lab_chroma_threshold` | 10 | 要求更大颜色差 |
| `lab_lightness_threshold` | 16 | 要求更大明暗差 |
| `piece_color_tolerance_lab` | 32 | 指定颜色允许更大综合色偏差 |
| `piece_color_tolerance_chroma` | 12 | 指定颜色允许更大色度偏差 |
| `background_difference_threshold` | 20 | 背景差分更严格 |
| `min_area_mm2` | 100 | 过滤小污点，也可能漏掉小碎片 |
| `max_area_mm2` | 6500 | 允许更大的单块 |
| `paper_margin_mm` | 3 | 忽略更多 A4 外边附近区域 |
| `divider_margin_mm` | 4 | 忽略更多分界线附近区域 |
| `morph_open_mm` | 0.6 | 更强去除小噪点 |
| `morph_close_mm` | 2.2 | 更强填补反光孔洞，也可能粘连近邻 |

题目限制：

- `max_pieces=4`；
- 基础模式 `required_pieces=4`；
- 提高模式运行时自动允许 2～4；
- 结构边数通常为 3～5；
- 普通直边最小长度由 `minimum_detected_edge_mm` 控制。

### 防止 A4 外边误识别为碎片

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `reject_roi_border_components` | true | 开启边缘伪分量检查 |
| `roi_border_component_min_contact_mm` | 8 | 接触边界超过此长度才可疑 |
| `roi_border_piece_colour_tolerance_lab` | 18 | 与内部真碎片同色则保留 |
| `roi_border_no_reference_contact_mm` | 18 | 没有内部参考时，仅删除很长残边 |

这组参数不要改成“只要接触就删除”，否则真实贴边碎片会漏识别。

## 5. 多边形参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `polygon_epsilon_mm` | 1.0 | 初始轮廓简化量 |
| `max_polygon_epsilon_mm` | 5.0 | 最大简化量 |
| `minimum_detected_edge_mm` | 8.0 | 普通片最短有效边 |
| `minimum_corner_turn_deg` | 30 | 普通片最小转角 |
| `expected_min_vertices` | 3 | 最少结构顶点 |
| `expected_max_vertices` | 5 | 最多结构顶点 |

轮廓毛刺多：小幅增加 `polygon_epsilon_mm` 或 `morph_close_mm`。  
小边被吞掉：降低 `polygon_epsilon_mm`，不要先放宽到超过 5 个结构边。

## 6. 扑克牌专用参数

只在 `unknown-pattern` 模式使用。

| 参数 | 默认值 | 建议范围 |
|---|---:|---:|
| `card_expected_total_area_mm2` | 5016 | 按实际整牌面积标定 |
| `card_minimum_long_side_mm` | 83 | 牌长边下限 |
| `card_maximum_long_side_mm` | 93 | 牌长边上限 |
| `card_minimum_short_side_mm` | 52 | 牌短边下限 |
| `card_maximum_short_side_mm` | 62 | 牌短边上限 |
| `card_rounded_chord_min_mm` | 2 | 圆角短弦下限 |
| `card_rounded_chord_max_mm` | 8 | 圆角短弦上限 |
| `card_glare_overexposed_ratio` | 0.55 | 反光过强时降低花纹权重 |
| `card_search_seconds` | 2.2 | 总搜索时间上限之一 |
| `card_exact_search_seconds` | 0.55 | 精确阶段时间 |

优先级：

1. 轮廓几何与整牌尺寸；
2. 无镜像、无重叠和矩形边界；
3. 可见花纹、数字与接缝连续性；
4. 反光遮挡花纹时自动退回轮廓。

不要把整牌长短边范围设置得比真实测量宽很多，否则会增加错误矩形和搜索时间。

## 7. 普通未知拼图求解参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `min_width_mm` / `max_width_mm` | 90 / 120 | 目标矩形宽范围 |
| `min_height_mm` / `max_height_mm` | 50 / 90 | 目标矩形高范围 |
| `edge_length_tolerance_mm` | 4.5 | 接缝绝对长度容差 |
| `edge_length_relative_tolerance` | 0.12 | 接缝相对容差 |
| `max_search_seconds` | 1.2 | 主搜索时间 |
| `fallback_search_seconds` | 1.0 | 回退搜索时间 |
| `minimum_accepted_fill_ratio` | 0.90 | 最低填充率 |
| `maximum_accepted_geometry_score` | 16 | 最大几何误差分 |
| `maximum_accepted_pair_overlap_mm2` | 100 | 搜索候选阶段容差 |
| `motion_boundary_snap_tolerance_mm` | 0 | 最终机械动作不越界 |

“候选搜索可有容差”不等于最终允许重叠。最终输出仍检查 `target_non_overlapping=true` 和 `mirrored=false`。

## 8. 推荐调参顺序

1. 先解决 A4 绿框；
2. 再解决橙色分界线；
3. 再解决碎片数量和边框；
4. 最后调求解器。

不要在 A4 或碎片轮廓错误时调求解器，否则只会让错误输入更快地产生错误方案。

## 9. 常见现场配方

### 黑色 A4、白色碎片

- 网页设置 A4 为黑色、碎片为白色；
- 勾选优先颜色；
- 保持 `edge_refine_enabled=true`；
- 银色线反光时不要降低分界线连续宽度；
- 若纸外亮条误识别，保持边缘伪分量检查开启。

### 蓝色 A4、白色碎片

- 默认参数通常可直接使用；
- 光线偏黄时优先用网页颜色提示；
- 白片漏检时先把 `lab_lightness_threshold` 从 16 调到 13～15。

### 白色 A4、白色碎片

两者缺少颜色差，不推荐。必须使用阴影、边线或空白背景差分，否则任何纯色算法都难以稳定分离。

### 强反光扑克牌

- 使用 `unknown-pattern`；
- 尽量使用大面积漫射灯；
- 固定曝光，避免自动曝光来回变化；
- 花纹不可见时让程序按轮廓回退，不要强制提高花纹权重。

## 10. 性能档位

RDK X5 推荐保持默认值。PC 性能充足时可将：

```json
"detection_max_dimension": 1200,
"fallback_detection_max_dimension": 1800
```

以换取略高边缘精度。若实时性优先，先降低网页分析频率或摄像头分辨率，不要关闭最终无重叠与禁止镜像校验。
