# 版本说明与验证记录

版本：2026-07-31 RDK X5 / Windows PC 统一版

## 本版主要更新

1. RDK X5 与 Windows PC 使用完全相同的最新视觉算法。
2. A4 定位由“单次粗框”升级为“粗定位＋原图四边 Lab 色差精修＋比例/分界线复核”。
3. 黑色、深色 A4 支持亮色分界线；普通彩纸支持暗色分界线。
4. A4 外侧桌面残边不再冒充第 3、4 块碎片。
5. 边缘候选增加同色保护，真实碎片靠近纸边时不会仅因接触边界被删除。
6. 提高模式支持 2、3、4 块碎片。
7. 固定模式、普通白片模式和扑克牌模式分流，扑克牌搜索不会拖慢前两种模式。
8. 拼图动作只含旋转和平移，任何模式均禁止单块镜像。
9. 下方矩形使用与源碎片对应的颜色绘制。
10. 机械臂 JSON/CSV 输出吸取点、放置点、旋转角和目标多边形。
11. Windows PC 增加依赖安装、启动和完整自检 BAT。
12. RDK X5 增加启动/停止 Shell 脚本及 Windows SSH 一键部署工具。

## 当前默认策略

- 正式题固定四片：`fixed`；
- 普通 2～4 片：`unknown-white`；
- 扑克牌/花纹：`unknown-pattern`；
- 摄像头源区域：`upper`；
- RDK/PC 网页端口：`8000`；
- A4 物理尺寸：210×297 mm；
- 分界线理论位置：148.5 mm。

## 交付边界

本包完成视觉检测、拼图规划、画面叠加及机械臂动作数据导出，不直接控制机械臂电机、吸盘或安全急停。机械执行前必须由控制程序检查 `motion_ready`、`mirrored=false` 和 `target_non_overlapping=true`。
