# Puzzle Vision Simulator

This repository contains the public vision, planning, calibration, and MuJoCo
simulation code for the puzzle-assembly system.

The main project is in [`puzzle-vision-simulator/`](./puzzle-vision-simulator/).
Start with its [`使用教程.md`](./puzzle-vision-simulator/使用教程.md),
[`docs/architecture.md`](./puzzle-vision-simulator/docs/architecture.md), and
[`CONTRIBUTING.md`](./puzzle-vision-simulator/CONTRIBUTING.md).

Machine-specific calibration, captured data, competition materials, reference
code, and the controller/firmware project are deliberately excluded from the
public tree. See the project configuration and data READMEs for setup details.
